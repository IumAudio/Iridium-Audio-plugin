### Final Ceiling 真峰值天花板（重写 `FinalCeiling.h`）
- 参照 Tukan S2 的 **detection-only** 真峰值检测：音频走基频不重采样，仅用一套 16× 过采样（与核心 OS 同款）把每个基频样本插成 16 个子样本，取两声道 max(|子样本|) 作为真峰值。
- **1ms 前视**（同 Tukan S2；与基底 50ms 分段前视无关），让增益在真峰值到达前降下来；逐样本峰值包络瞬时攻击 + 19ms 释放、增益瞬时攻击 + 50ms 释放。
- FC 开 = 0 dBFS 真峰值压顶；FC 关 = 只做 1ms 透明延迟（增益 1），延迟恒定、切换无爆音。
- 关键纠正：上一版把 FC 塞进 16× 音频域、且位于核心限幅器之后 —— 核心限幅器已把 16× 样本压到 0 dBFS，FC 无峰可压（假真峰值）。改为基频域 + 检测专用 16×。
- 只取真峰值检测 + 压顶，不带 Tukan 的 maximizer / 包络个性；删除写错的 `TukanLimiterS2.h`。

### 信号链与延迟（`PluginProcessor`）
- 新顺序：输入 trim → 核心限幅器（16× OS，OS 开）→ 降采样 → 输出 trim → **Final Ceiling（基频域，FC 开）** → 输出表 → LUFS。
- 删除末级软/硬削波 waveshaper（headroom/tau 段）。
- 延迟 = 50ms 前视 + OS 滤波延迟（仅 OS 开）+ 1ms Final Ceiling（恒定，FC 开关不改变）。FC 关时仍经过 OS，只是不做真峰值压顶（增益 1）。

### LUFS 采样率修复（`ShortTermLoudness.h`，自 v0.1.1beta 取回）
- BS.1770 K 加权由固定 48kHz 系数改为按宿主采样率重算（双线性 tan），严格 3s 滑窗 + Kahan 补偿求和。
- 自带 `#pragma float_control(precise, on, push/pop)`，Kahan 补偿不受全局 `/fp:fast` 破坏 → CMake 保持 `/fp:fast` 不动（不牺牲核心限幅器性能）。

### UI 手感（`IridiumUI.html` + `PluginEditor.cpp`）
- **Ctrl+双击旋钮数值 = 键盘输入**：隐藏 `<input>` + Ctrl+双击才显示；普通单击不触发（数值 `.knob-val` 保持 `pointer-events:none`）、普通双击仍复位归零。Enter 提交 / Esc 取消 / 失焦提交有效值、越界非法拒绝。
- **旋钮键盘**：方向键每格 0.5 dB、Shift 0.01 dB、Home 归零（`tabindex=0` + 聚焦高亮）。
- 采样率读数按用户要求**移除**（`#sampleRate` 元素、CSS、`S.sampleRate`、C++ 推值全部删除）。

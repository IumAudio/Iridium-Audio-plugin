# 开发日志 · 2026-09-30

## 第二十四阶段：v0.1.1test —— 从 v0.1.0 重做 Final Ceiling 真峰值 + LUFS 采样率修复 + UI 手感

### 用户需求（本轮）
1. 全部退回 v0.1.0，重新来（不保留 v0.1.1beta 的连续增益场 / Ceiling 旋钮 / emit 事件桥等）。
2. 保留 v0.1.1beta 的：采样率 bug 修复、UI 手感（不涉及声音的 UI 修复）、side 通道放大倍数计算、Ctrl+双击键盘输入数值（普通单击不触发）。
3. 新增 true peak 功能，内置在 FC 里，FC 开时启用；算法参考开源 Tukan Limiter S2。
4. 关键指正：名称统一叫 **Final Ceiling**；只取 Tukan 的 **true peak 检测**；检测仍用 **16×**（不是 Tukan 的 8×）；前视改 **2ms**；**不要和插件基底 50ms 前视混淆**；**FC 与 OS 是独立开关，互不影响**。
5. 削波确实要移除（核心限幅器硬削波 + 末级软/硬削波都删）。

### Final Ceiling 真峰值天花板（新 DSP `FinalCeiling.h`）
- 自带一套**独立 16× 检测过采样**（`juce::dsp::Oversampling` 2×4 半带，与核心限幅器同款但独立实例），**不受 OS 开关影响**——FC 开/关 与 OS 开/关 四组合互不影响。
- **2ms 前视**（仅本阶段，与基底 50ms 分段前视无关）；峰值包络瞬时攻击 + 20ms 释放、增益瞬时攻击 + 50ms 释放（> 前视，峰到输出时增益仍在）。
- FC 开 = 16× 真峰值检测（上限 0 dBFS 真峰值）；FC 关 = 样本峰值检测（上限 0 dBFS 样本峰值），共用同一 2ms 延迟、切换不爆音。
- 只取真峰值检测 + 压顶，不带 Tukan 的 maximizer / 包络个性。
- 删除写错的 `TukanLimiterS2.h`。

### 信号链与延迟（`PluginProcessor`）
- 新顺序：输入 trim → 核心限幅器（16× OS）→ 输出 trim → **Final Ceiling** → 输出表 → LUFS。
- 删除末级软/硬削波 waveshaper（headroom/tau 段）。
- 延迟 = 50ms 前视 + OS 滤波延迟（仅 OS 开）+ 2ms Final Ceiling（固定），FC 开关不改变延迟。

### LUFS 采样率修复（`ShortTermLoudness.h`，自 v0.1.1beta 取回）
- BS.1770 K 加权由固定 48kHz 系数改为按宿主采样率重算（双线性 tan），严格 3s 滑窗 + Kahan 补偿求和。
- 自带 `#pragma float_control(precise, on, push/pop)`，Kahan 补偿不受全局 `/fp:fast` 破坏 → CMake 保持 `/fp:fast` 不动（不牺牲核心限幅器性能）。

### UI 手感（`IridiumUI.html` + `PluginEditor.cpp`）
- **Ctrl+双击旋钮数值 = 键盘输入**：隐藏 `<input>` + Ctrl+双击才显示；普通单击不触发（数值 `.knob-val` 保持 `pointer-events:none`）、普通双击仍复位归零。Enter 提交 / Esc 取消 / 失焦提交有效值、越界非法拒绝。
- **旋钮键盘**：方向键每格 0.5 dB、Shift 0.01 dB、Home 归零（`tabindex=0` + 聚焦高亮）。
- **采样率读数**：LUFS 表下方新增 `#sampleRate`，C++ `pushMeters` 推 `S.sampleRate`。
- FC 按钮 title / 手册文案更新为「真峰值 / 样本峰值」语义，并注明 FC 与 OS 独立。

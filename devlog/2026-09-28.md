# 开发日志 · 2026-09-28

## 第二十三阶段：v0.2.0 —— LUFS 表 + 原子动画彩蛋 + 0.01dB 精度 + 峰值限幅回退

### 用户需求（本轮）
1. 输入/输出调节精确到 0.01 dB 分度值；Shift 滚轮 = 0.01 dB 精细。
2. Input 电平旁加「原子」装饰并做成可动动画：三条环要转起来、电子要是立体的小球（比核小）、默认静止、点击原子核开启动画（彩蛋）。
3. 峰值限不住 → 回退到旧逻辑。

### LUFS 表（新增，DSP + UI）
- `PluginProcessor`：ITU-R BS.1770 K 加权（阶1 高频搁架 + 阶2 高通，48kHz 标准系数）+ 400ms 均方块 + 3s 滑窗（8×400ms），测输出信号；`-0.691 + 10·log10(均值)`。48kHz 标定，其它采样率近似。
- `PluginEditor::pushMeters` 每帧推 `S.lufs`。
- UI：Input 电平下方 `#lufsBox`（暗底 + 虹彩描边），无信号显示 `-∞`。

### 原子动画（UI 彩蛋，多轮迭代后定稿）
- 结构：`#inAtom` → `.spin`（整体 rotateY）→ `.orbit`（静态 rotateX70 + rotateY0/60/120 错开）→ `.path`（rotateZ 自转）→ `.efix`（反旋转抵消 path 自转）→ `.electron`（6px 球形）。
- 关键认知（查经典实现）：环「绕自身轴转」对正圆不可见；正确是「轨道静态 3D 倾斜 + path 绕自身轴转 + 电子反旋转」三层，配合 `perspective + preserve-3d`。
- 默认静止（无 `.on` 不播动画）：电子停在各自轨道「最尽头」（椭圆长轴端点：右端 / 左上 / 左下）。
- 点击原子核（`.nucleus`，`pointer-events:auto` + `cursor:pointer`）toggle `#inAtom.on` 开启动画（彩蛋）。
- 轨道颜色多轮调亮（蓝 .26 → .55、紫 .28 → .58、金 .24 → .52）。

### 峰值限幅回退（DSP）
- 2ms 前视峰值限幅 bug：峰值包络在前视窗口内衰减，峰值样本出延迟线时增益已回弹 → 峰值没压住。
- 回退到逐样本软拐角限幅（FC 开 headroom=0 硬顶 0dB；FC 关 headroom=0.5 软拐角），延迟恢复 50ms 前视，删除 `tpDelay/tpPeakEnv/tpLook` 成员。

### 0.01 dB 精度 + Shift 修复（两个同步 bug）
- 参数 step 0.1 → 0.01；显示 `toFixed(2)`；`Math.round(v*100)/100`；滚轮普通 0.5 dB、Shift 0.01 dB。

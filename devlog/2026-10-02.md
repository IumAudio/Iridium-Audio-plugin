- **JUCE 9 对齐官方模板**：`CMakeLists.txt` 删掉 `EDITOR_BACKEND`（9.x 已移除）、`PLUGIN_DESCRIPTION → DESCRIPTION`、`VST3_CATEGORY "Fx|Dynamics" → VST3_CATEGORIES Fx Dynamics`；`PluginProcessor.h` 补 `using AudioProcessor::processBlock;` + `isBusesLayoutSupported` + `isMidiEffect`。用 `juce-9.0.3-windows` 重新 configure + 全量编译成功。

## 第二十七阶段：恢复硬顶 + 高级 FC（16× 前视平滑增益 + tanh 软顶兜底）

### 用户需求
1. 推 input 像 trim 一样完全没限制——发现 v0.1.0 → 现在的过程中 limiter 内部逐样本硬顶被删、FC 也被删，段增益场之外无兜底（16× 降采样过冲 + output trim 正增益都没人压回）。
2. 恢复 v0.1.0 硬顶；FC 要求用「先进算法」做到更小失真——最终选定「两者结合」：**16× 域内前视平滑增益做主限幅 + tanh 软顶兜底**。

### 已完成
- **恢复硬顶**：`IridiumLimiter::process` 末尾恢复 v0.1.0 逐样本硬顶（double 域），兜底保证 0 dB。
- **新建 `FinalCeiling.h`**（前视真峰限幅器，非静态 waveshaper，16× 抗混叠）：
  - `detOS` 16× 上/下采样；
  - 2 ms 前视延迟线 + 单极点平滑增益（攻击 0.5 ms / 释放 20 ms，正确方向 `g += coef*(target-g)`）；
  - tanh 软顶兜底（`headroom≈0.05` ≈ +0.4 dB，只处理残峰）；
  - FC 关 = 仅过采样对齐延迟（透明）。
- **重新接线**：`PluginProcessor` 加回 `finalCeiling`/`fcParam`/`fcLatency`；信号链 = input gain → limiter（硬顶）→ output trim → FC → 表头；`fcLatency` 重新计入 `setLatencySamples`。
- UI 按钮 title / 手册文案改回 FC 真实功能说明。

### 产物
- `Iridium.vst3` 已重新编译部署到 `C:/Program Files/Common Files/VST3/`。

### 待办

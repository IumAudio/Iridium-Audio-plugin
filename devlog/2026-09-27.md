## 已完成

### 1) 抹掉 release（纯分段恒定增益）
- `Source/dsp/IridiumLimiter.h`：删除 ~0.5ms「fast staging」平滑（`smoothGain` / `smoothCoeff` 两个成员及相关计算）。
- 增益改为**纯分段恒定**：只在过零点对 `currentGain` 一步阶跃切换，无任何平滑 / attack / release 时间常数。段内增益 = ceiling ÷ 段峰值（局部极值约束），峰值精确贴顶。

## 关于「1 万 Hz 以上频率不被抬升」的分析（待用户确认场景）
- 整个信号链（输入增益 → 16× 过采样 → 分段增益 → 末级软拐角）**在频率上是平坦的**：增益 g(t) 每半周期恒定、对段内所有频率同乘；末级软拐角只对「超过 ceiling 的样本」起效，与频率无关。
- 唯一与频率相关的是过采样半带滤波器，但其阻带/滚降在**基带奈奎斯特附近（约 19–24kHz）**，10kHz 处是平坦的，不构成「10kHz 以上不抬升」。
- 最可能的原因：**宽带限幅在过驱动时先压住最响的成分**（瞬态/高频常最贴近 ceiling），提升 Input 时低频仍有余量继续升、高频却先被压回 ceiling，听感上「高频没被抬起来」。本次将 Output 默认改 0 dB，插件在默认状态下完全透明（只有超过 0 dBFS 才限幅），大概率已消掉该观感。
- 待用户提供具体测试信号 / 场景，若仍复现再深入（例如是否要 4× 替换 16×、或末级软拐角参数再调）。

- 本轮多次试错 + 即时纠正，**DSP 最终全部撤回、与 v0.0.9 一致**：
  - 曾计划「FC 开降 Ceiling 到 −0.5dB」→ 用户否：「不要 Ceiling，通过其他手段限峰」→ 撤回。

  - 过采样 IIR → FIR（线性相位）→ 用户否：「不要动过采样，我要 16×」→ 撤回，恢复 **IIR 16×**（factor=4，倍率从未改过）。
  - 前视 50 → 52ms → 用户「减小两毫秒」→ 恢复 **50ms**。
- 最终 DSP：与 v0.0.9 完全一致（16× IIR 过采样、50ms 前视、基频域末级硬顶）。

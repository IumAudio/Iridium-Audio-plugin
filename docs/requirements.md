# Iridium — 项目需求文档

## 项目概述
一个与传统算法不同的 limiter（限幅器），基于「基于局部极值约束与零点锚定的前视增益场构造器」这一新算法模型，实现为该模型下的一个数学解。

## 核心算法思想
- 输出形式：**y = f(x) · g(t)**
  - f(x)：与波形瞬时值相关的基础处理（类似限幅/形状函数）
  - g(t)：随时间连续变化的「前视增益场」，由局部极值与过零点共同构造
- **局部极值约束**：波形局部峰/谷作为增益场 g(t) 的控制点，保证峰值压到阈值以内
- **零点锚定**：增益变化在过零点处对齐，避免咔哒声与不连续
- **前视增益场**：g(t) 在向前看的窗口内连续绘制，不是固定 lookahead
- **50ms 是 buffer**：用于构造增益场，不是传统 lookahead 延迟
- **16x 过采样**：提高过零点检测精度（普通采样率下采样点可能落在 0.02/0.04 而非 0）

## 与 waveshaper 的本质区别
| | Waveshaper | Iridium |
|---|---|---|
| 数学形式 | y = f(x) | y = f(x) · g(t) |
| 时间相关 | 无关 | 相关 |
| 上下文 | 同一波形同一结果 | 上下文不同结果不同 |
| 记忆 | 无 | 有（前后峰值/零点） |

# Iridium — 算法设计文档

> 状态：v0.0.7 已落地（2026-09-27 首个公开版）。§1–§7 为首版推导 + 设计决策（§6 已在实现中逐条敲定），§8–§12 为逐版落地记录；当前 DSP 最终状态见 §12。

## 1. 模型定义

输出形式：

**y(t) = f(x(t)) · g(t)**

| 符号 | 含义 | 待定项 |
|---|---|---|
| x(t) | 输入波形（检测在 16x 过采样域进行） | — |
| f(x) | 无记忆瞬时转移（软削波 / 硬顶），提供绝对上限 | 具体形式待定（§6.1） |
| g(t) | **前视增益场**（本算法核心，时变、上下文相关） | 构造方式本文推导 |

与 waveshaper 的本质区别：waveshaper 是 y=f(x)，时间无关、无记忆；本算法 g(t) 依赖前后峰值与过零点，同一波形在不同上下文下 g(t) 不同 → 输出不同。

### 灵感来源

- **Xilentch XMLimiter 2**（用户指定灵感来源）：无前视延迟、实时跟踪、**只在峰值处下压**（不整体压头）、16× 过采样。Iridium 吸取其「只压峰值、保冲击力」的精神；实现路线不同——Iridium 走**分段前视（过零点锚定 + 半周期恒定增益）**，XMLimiter 2 走零延迟实时跟踪。参考文献与现有技术对照见 §5。

## 2. 检测（16x 过采样域）

### 2.1 过采样
- 16x 过采样（JUCE `Oversampling` factor=4，注意 factor 是 2^factor 语义）。
- 目的：普通采样率下采样点可能落在 0.02/0.04 而非精确 0，过零检测不准；16x 下更容易抓到真正零点与真实峰（true peak）。
- 对比：true-peak 计量标准（ITU BS.1770）只用 4× 过采样；本算法用 16× 是刻意提高，因为过零检测比 true-peak 计量更需要亚采样精度。

### 2.2 过零检测（分数零点）
相邻异号样本 (t1, x1)、(t2=t1+Ts, x2)，线性插值求过零时刻（Altice & Meer 1991）：

**t̂ = t1 + Ts · x1 / (x1 − x2)**   （等价于 t1 + Ts·|x1|/(|x1|+|x2|)）

得到过零点集合 {τ_j}（分数样本位置）。

### 2.3 局部极值检测
- |x̃| 的局部极大：样本 n 为峰，若 |x̃[n]| ≥ |x̃[n−1]| 且 ≥ |x̃[n+1]|。
- 幅值 A_i = |x̃(t_i)|；可用三点抛物线插值细化峰位置与幅值。
- 最小峰间距 / 幅值阈值等，参考 ISMIR 2012「峰值挑选方法」做后处理（待定参数）。

## 3. 峰值约束（局部极值约束）

每个峰 (t_i, A_i) 的**所需增益**：

**g_i = min(1, T / A_i)**

- A_i ≤ T（不越界）→ g_i = 1（不衰减）
- A_i > T → g_i = T / A_i（把峰压到阈值 T）

约束条件：增益场 g(t) 在每个峰时刻满足 **g(t_i) ≤ g_i**。

## 4. 前视增益场 g(t) 的构造（核心）

### 4.1 零点锚定的原理
过零点处 x=0，故 y = x·g 在该处恒为 0，与 g 无关。因此 **g 在过零点处改变取值不会造成输出断点（咔哒声）**。这就是「零点锚定」的数学依据。

### 4.2 构造（v1 推荐：分段恒定 + 前视）
1. 用过零点把信号切成段 [τ_j, τ_{j+1}]。
2. 每段内取峰值幅值 A_seg = max |x̃|，段所需增益 G_j = min(1, T / A_seg)。
3. 前视：利用 50ms buffer 提前知道未来各段，把 g(t) 在**当前段开始（即过零点 τ_j）处**就设到未来峰值所需的低值，再在峰值过后恢复。
4. g(t) 在段内恒定、段界（过零点）处变化 → 数学上保证无咔哒。

### 4.3 平滑插值（v2 升级，对应「连续绘制」）
- 以过零点 τ_j 为节点，节点值 G_j（前视赋值，规则同 4.2）。
- 节点间用**单调插值**（线性 或 PCHIP 单调三次）连成连续曲线 g(t)。
- 关键：普通三次样条会**过冲**（越过节点值），可能突破峰值约束；须用单调保形插值或斜率钳制（MPEG-D DRC 即用「增益值+时间+斜率」编码样条节点，见 §5）。
- 前视赋值规则（v1）：G_j = min(1, min{ g_i : 峰 t_i 落在前视窗口 [τ_j, τ_j+W] 内 })。

### 4.4 前视窗口（50ms buffer）
- 长度 W ≈ 50ms，用于提前看到峰值、提前把增益降到位（攻击不滞后）。
- 语义：是「构造 g 用的缓冲」，不是传统 lookahead 延迟；输出对齐引入的恒定延迟需上报 PDC。

### 5.2 最接近的现有技术（重要：供大佬评估新颖性）

- **专利 US 2004/0002313 A1「Signal level control」（Allan Peace，2002 申请 / 2004 公开）**：抽头延迟线 + 过零检测器 + 采样保持，**只在过零点处**根据预测的峰值调整增益（gain ∝ 1/预测峰值，钳到阈值）。→ 这就是「零点锚定 + 前视 + 峰值约束」的**先例**，已过期（2002 年申请，专利期约 20 年）。
- **专利 EP 2070191（Audio peak limiting in slow and fast stages）**：两级（慢/快）增益 + lookahead 延迟；第一级按 excursion 检测算增益，第二级更快；Hanning 窗派生平滑系数 + 慢化 Newton-Raphson。→ 经典 lookahead 限幅器架构的专利化。
- 实践文档：Omnia《The Basics of Look-Ahead Processing》、tonalux《Lookahead Limiting and Peak Anticipation》、signalsmith《Designing a straightforward limiter》。

> 诚实说明（重要）：**「在过零点切换增益」这个核心动作本身不是新东西**——2002 年就有专利（US 2004/0002313 A1，已过期）。Iridium 相对现有技术**真正可能「新」的部分**在组合与构造方式：
> 1. g(t) 作为**连续增益场**，用单调保形插值（PCHIP）在过零点节点间连续绘制（该专利是分段恒定）；
> 2. **16× 过采样**下的亚采样精度过零检测（true-peak 标准只需 4×）；
> 3. 显式 f(x)·g(t) 形式 + min(1, T/A_i) 极值约束的系统化推导。
> 新颖性结论建议由大佬最终判定。

## 6. 待确认的设计决策

> 已全部定案（逐条对应落地记录）：① f(x)=恒等，g 主限幅，f 仅基频域软拐角兜底（§10）；② g(t)=分段恒定纯阶跃，未升级 PCHIP（§9）；③ 前视赋值=半周期分段恒定，无 attack/release（§8–9）；④ 全程 16× 过采样域处理，基频域仅末级兜底（§8、§10）；⑤ 链接式立体声（max(|L|,|R|) 驱动 + mid 过零锚定）（§8）；⑥ T 固定 0 dBFS（§11.3）。

1. **f(x) 具体形式**：恒等 + 最终硬顶 / 软削波（tanh / cubic）？建议：g 做主要限幅，f 只做安全兜底软削波。
2. **g(t) 构造**：v1 分段恒定（最稳、零过冲）还是 v2 平滑插值（更「连续绘制」）？建议先 v1 跑通、再升级 v2。
3. **前视赋值规则**：min-前视（激进、紧贴峰值）还是带 attack/release 平滑（自然、留余量）？
4. **处理域**：仅在过采样域检测、基频域处理，还是全程过采样域处理？（影响 CPU 与延迟）
5. **立体声策略**：L/R 独立检测共享同一 g(t)（避免声像漂移）或 M/S？
6. **峰值阈值 T**：默认 ceiling 值（如 −1 dBFS）与是否做 true-peak 兜底。

## 8. v0.0.1 实现 —— 分段前视增益场（两个半周期 + fast staging，已落地）

> 状态：v0.0.1（2026-09-26 落地）。按用户反馈（「Lookahead 分段进行、分管 fast staging、两个半周期」）重新推导的最终版本。

### 8.1 最终模型

**g(t) = C / Pᵢ**（t 落在第 i 个半周期 Hᵢ 内），其中：
- C = ceiling（线性），Pᵢ = 半周期 Hᵢ 内 max|x|（局部极值）。
- 半周期 = 相邻两个过零点之间的段。

推导（三点）：
1. **零点锚定**（US 2004/0002313 A1）：过零点 x=0 → y=x·g=0 与 g 无关 → 增益只在过零点切换，无咔哒。
2. **局部极值约束**：|y| ≤ C ⟹ g ≤ C/Pᵢ；最透明解 = 恰好取等（g = C/Pᵢ，峰值贴顶、不多压）。
3. **分段恒定**：增益只在过零点切 → 段内恒定 → g(t) 是分段常数函数，即「合理的函数解」。

### 8.2 两个半周期前视（fast staging）

- 要压 Hᵢ 的峰 Pᵢ，必须在其到来前就知道 Pᵢ；故输出延迟一个半周期。
- 实现：固定 50ms 缓冲（覆盖「两个半周期」，20Hz 以下由硬顶兜底）；输入域按过零点分段累积峰值、段结束把 g=C/P 入队；输出域在延迟后的过零点处弹出对应增益。
- 「fast staging」= 增益在过零点处用亚毫秒（~0.5ms）单极点平滑过渡，去掉分段恒定的斜率跳变（否则 y′=x′·g 在过零点跳变 → 谐波）。这是去阶跃的平滑，**不是 attack/release 时间常数**（无不对称、无包络跟随）。（**v0.0.2 已删除该平滑，改为纯阶跃，见 §9**）

### 8.3 修复的低频 bug

v1.2 的「低频突然丢一块」根因：5ms 定长前视窗 < 低频半周期，峰值没被整段覆盖 → 硬顶切掉一块。
修复：改为按半周期分段，增益覆盖整个半周期 → 低频峰不再逃出。

### 8.4 与文献的对应

| 构件 | 文献 |
|---|---|
| 零点锚定（过零点切增益） | US 2004/0002313 A1（Allan Peace 2002） |
| 前视增益曲线 / 防削波 g=min(1,T/e) | Hämäläinen 2002 (DAFx) |
| 无记忆 hard clip 兜底 | Giannoulis & Reiss 2012 (JAES) 分类 |
| 16× 过采样 | 比 BS.1770（4×）刻意更高，为抓精确零点 |

## 9. v0.0.2 变更 —— 抹掉 release + 基频兜底压峰（已落地）

> 状态：v0.0.2（2026-09-27 落地）。用户确认 v0.0.1 基本没问题后的收尾。

### 9.1 删除 fast staging（纯分段恒定）
- §8.2 的 ~0.5ms 单极点平滑（`smoothGain`/`smoothCoeff`）已删除。
- 增益改为**纯阶跃**：g(t) 在过零点一步切到 C/Pᵢ，无任何平滑 / attack / release 时间常数。
- 代价：过零点处 y′=x′·g 的斜率跳变（原 fast staging 想消除的谐波）恢复；但因相邻半周期增益多为连续值（C/P 随峰缓变），且切换点恰在 x=0（信号能量最小处），听感无咔哒。
- 收益：彻底抹掉用户感知的「release 回弹」。

### 9.2 基频域 Final Ceiling（抓微小峰值）
- 16× 过采样降采样（`processSamplesDown`）的 FIR 滤波器过冲，会让个别样本冒出 ceiling 一点点。
- 处理：降采样后在基频域对输出再硬顶到 ±C —— 只削多余那「一点点」，不整体压头、不伤瞬态冲击力。（**v0.0.3 硬顶改软拐角，见 §10**）
- 位置：`PluginProcessor.cpp` processBlock 第 5 步。

### 9.3 分层小结
- 过采样域内仍是 §8 的分段恒定增益场（C/Pᵢ）＋ 过采样域硬顶；基频域 Final Ceiling 是最后一层兜底，专抓降采样过冲的微小峰值。

## 10. v0.0.3 变更 —— 末级软拐角 + 放大 UI + 尺寸可调（已落地）

> 状态：v0.0.3（2026-09-27 落地）。用户反馈末级硬切「有一点点过」，且 UI 需放大、Input/Output 并排、元素牌右置、加尺寸调节。

### 10.1 末级硬切 → 软拐角（更温和 + 更高质量）
- v0.0.2 的基频域硬顶 `clamp(x, ±C)` 在过冲样本处产生硬切拐角（瞬态上极轻微的生硬），用户反馈「过了一点点」。
- v0.0.3 改为软饱和：|x| ≤ C 完全透明；|x| > C 用 `C + headroom·(1 − e^(−(x−C)/τ))` 柔和压回，渐近 C + headroom。
  - headroom ≈ 0.006C（~0.05 dB）：允许极微残余、不硬切，比硬顶更温和；
  - τ = 0.3C：软饱和尺度，过冲越大压得越狠，但始终平滑无拐角。
- 代价：每样本一次 `exp`（舍弃一点点性能，换取更少硬切失真、更稳定温和）。
- 效果：微小过冲仍被精确抓回（≈0.01 dB 内），但不再产生硬切瞬态。

### 10.2 UI（不影响 DSP）
- 窗口基准 720×460 → 760×500；旋钮 150→200px；Input/Output 并排等大同款；元素牌右置；新增尺寸调节（0.7×–2.0×，`uiZoom` 持久化）。

## 12. v0.0.7 变更 —— 软拐角最终参数 + 最终算法状态（已落地并发布）

> 状态：v0.0.7（2026-09-27 首个公开版）。clip 斜率更陡 + 微峰值再收一点点。

### 12.1 v0.0.7 软拐角最终参数
- `headroom` 0.003 → **0.0015**（残余余量 ~0.026dB → ~0.013dB，微峰值再收一点点）。
- `tau` 0.30 → **0.22**（软饱和尺度更小 → clip 斜率更陡、更贴顶）。
- 幅度克制（「改变不能太大」）：headroom 仅降 1.5 个基点、tau 降约 27%。

### 12.2 最终算法状态（v0.0.7 发布版）

**信号链**（`PluginProcessor::processBlock`，基频域视角）：
1. Input gain（±24 dB）
2. 16× 过采样
3. **IridiumLimiter**（分段前视增益场，Ceiling 固定 0 dB）
4. 降采样回基频
5. **末级软拐角安全限幅**（基频域）：|x| ≤ 1 完全透明；|x| > 1 用 `1 + 0.0015·(1 − e^(−(x−1)/0.22))` 柔和压回（渐近 1.0015，无硬切拐角）
6. **Output trim**（±24 dB，后置增益，非阈值）

**IridiumLimiter 内部**（16× 过采样域）：
- 链接式立体声：`mid = (L+R)/2` 驱动过零分段；段峰值 `segPeak = max(|L|,|R|)`。
- 半周期段：相邻过零点之间为一段；段增益 `g = clamp(1 / segPeak, 1e-4, 1)`（Ceiling = 1）。
- 前视：50ms 缓冲（覆盖两个半周期），输入域累积峰值入队、输出域在延迟后过零点**纯阶跃**切换增益。
- 无任何 attack/release 时间常数；过采样域内另有 ±1 硬顶兜底（防超长低频段）。
- 增益只在过零点切换（x=0 → y=x·g=0 与 g 无关 → 无咔哒）。

**关键数值**：

| 项 | 值 |
|---|---|
| Ceiling | 0 dBFS（固定） |
| 过采样 | 16×（factor=4） |
| 前视缓冲 | 50ms |
| 软拐角 headroom | 0.0015（~0.013 dB） |
| 软拐角 τ | 0.22 |
| Output trim | ±24 dB（默认 0） |
| 总延迟 | 过采样滤波器延迟 + 50ms ÷ 16 前视 |

## 13. 灵感来源与参考文献

### 13.1 灵感来源（软件）
- **Xilentch XMLimiter 2** —— 用户指定的灵感来源：零延迟实时跟踪、只在峰值处下压（不整体压头）、16× 过采样。Iridium 借鉴「只压峰值、保冲击力」的精神，算法路线改为**分段前视**（见 §1、§8）。

### 13.2 参考文献（论文 / 标准）
1. Hämäläinen, P. (2002), *DAFx-02*, pp. 195–198. —— 前视峰值限幅器控制曲线平滑 + 防削波；g(n)=min(1, T/e(n))。
2. Altice & Meer (1991), *NAECON*, vol. 1, pp. 112–118. DOI: 10.1109/NAECON.1991.165731. —— 线性插值求精确零点 + 误差分析（分数过零估计）。
3. Giannoulis, Massberg & Reiss (2012), *JAES* 60(6): 399–408. —— 单极点平滑 α=exp(−1/(τ·fs))；前馈 + 对数域检测推荐。
4. Gorlow & Reiss (2013), *IEEE TASLP* 21(7): 1434–1444, "Model-Based Inversion of Dynamic Range Compression". —— 显式 attack/release 模型（β=1−exp(−2.2/(fs·τ))）。
5. Fritsch & Carlson (1980), *SIAM J. Numer. Anal.* 17: 238–246. —— PCHIP 单调三次 Hermite，节点间不过冲（g(t) 连续绘制的插值方案）。
6. ISO/IEC 23003-4 (MPEG-D DRC). —— 增益控制点 + 样条插值 + 斜率换算。
7. ITU-R BS.1770 / AES-R7 (AES 17188). —— true-peak 计量标准（4× 过采样）；Iridium 用 16× 是刻意更高，为抓精确零点。
8. Fink, Holters & Zölzer (2016), *DAFx*. —— 控制点间连续过渡曲线（crossfade）形状。
9. Wei & Shimizu (2004), *NEWCAS*. —— 增益特性多项式插值先例。

### 13.3 现有技术（专利，供新颖性评估）
- **US 2004/0002313 A1**「Signal level control」（Allan Peace，2002 申请 / 2004 公开）—— 抽头延迟线 + 过零检测 + 采样保持，只在过零点按预测峰值调增益。「零点锚定」先例，已过期。
- **EP 2070191**「Audio peak limiting in slow and fast stages」—— 两级慢/快增益 + lookahead 延迟，经典 lookahead 限幅器架构的专利化。

> 诚实说明：核心动作「过零点切换增益」本身不新（US 2004/0002313 A1，已过期）。Iridium 相对现有技术可能「新」的部分：① g(t) 作为连续增益场的构造（PCHIP 插值，该专利是分段恒定）；② 16× 过采样下的亚采样过零检测；③ 显式 f(x)·g(t) + min(1, T/A) 极值约束的系统化推导。新颖性结论建议由大佬最终判定。

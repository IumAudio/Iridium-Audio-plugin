IRIDIUM

GAIN-FIELD LIMITER · v0.1.0

限幅原理 — 输出 y = f(x)·g(t)：把信号按过零点切成「半周期」，每段增益 = Ceiling ÷ 段峰值（局部极值约束），且只在过零点切换增益（零点锚定，无咔哒）。两段前视使增益提前就位，全程无 attack / release 时间常数。

控制 — INPUT 输入增益（±24 dB，精度 0.01 dB）；OUTPUT 末级输出微调 Trim（±24 dB，Ceiling 固定 0 dB）。FC Final Ceiling（开=硬顶 0dB、峰值精确贴顶；关=软拐角、峰值放出）。OS OverSampling（开=16× 过采样抗混叠；关=基频处理、更省 CPU）。LINK 连接 Input/Output（推起 Input 同时拉低 Output）。旋钮支持鼠标滚轮微调（普通每格 0.5 dB，按住 Shift 滚轮 = 0.01 dB 精细、拖动 = 灵敏度 ÷10）。Ctrl+Z 撤回 / Ctrl+Y 重做。左为输入电平（下方为 LUFS 短期响度表），右为输出电平与 GR 增益衰减。底部 − / + 调节界面尺寸。

元素 · 铱 Ir — 77 号，过渡金属，铂族。密度 22.56 g/cm³（仅次于锇），最耐腐蚀的金属。1803 年 Smithson Tennant 发现，名源自希腊语 iris（彩虹），因铱盐呈虹彩色。曾用于标准米原器与千克原器（铂铱合金）。

彩蛋 — Input 电平旁有一枚铱原子模型：点击原子核可开启动画（三条轨道旋转 + 电子绕行）。右上元素牌另有 K–Pg 边界彩蛋：白垩纪–古近纪边界遍布全球的「铱异常」层，是小行星撞击地球、导致恐龙灭绝的关键证据。
